Anonymous Thoughts 💌

Anonymous Thoughts is a full-stack anonymous messaging platform where users can anonymously leave thoughts for Senitha.

The platform includes secure authentication, admin moderation, and a modern black & pink aesthetic UI.

 Tech Stack

 Frontend
- HTML
- CSS
- JavaScript

Backend
- Node.js
- Express.js

 Database
- MongoDB
- Mongoose

 Authentication
- JWT (jsonwebtoken)
- bcryptjs



 Authentication Flow

1. User signs up or logs in
2. Backend verifies credentials
3. JWT token is generated
4. Token is stored in localStorage
5. Protected routes use middleware for verification
6. Admin user can moderate/delete messages
